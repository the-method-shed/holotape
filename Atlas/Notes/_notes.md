# Notes

Come here to develop an idea, question, or reference that remains useful beyond a single project. A note can connect several maps or project pages; it need not fit a topic folder. Follow those links to see why a note matters in context.

Have an unfinished thought or clipping? Capture it in the [+ inbox](../../+/_inbox.md). Before making it a durable note, review its provenance, sensitivity, and destination with a human. Link the reviewed note from a relevant [map](../Maps/Maps.md) or project; include sources for substantive claims and distinguish proposals from agreed decisions.

The [people map](../Maps/People.md) links to the profile stubs; [metadata conventions](Metadata%20conventions.md) documents draft page fields.

The view lists the newest notes directly in `Atlas/Notes/` by file creation time; pages in `Atlas/Notes/People/` are not included.
