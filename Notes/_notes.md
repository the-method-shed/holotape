# Notes

Durable cross-project notes live in this forest. A note can appear on several maps or project pages; it need not fit a topic folder. Include provenance for consequential claims and distinguish proposals from agreed decisions.

The [people map](../Maps/People.md) links to the new profile stubs; [metadata conventions](Metadata%20conventions.md) documents the draft page fields.

The view lists the 10 newest notes directly in `Notes/` by file creation time; pages in `Notes/People/` are not included.
